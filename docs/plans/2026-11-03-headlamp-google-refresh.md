# GKE Headlamp Google 자동 갱신 구현 계획

**목표:** 사용자별 Google 로그인 후 토큰을 자동 갱신하는 GKE 전용 Headlamp를 준비한다.

**구조:** 기존 AWS Headlamp를 보존하고 `/gke` 경로에 별도 OAuth2 Proxy와 loopback Headlamp를 배치한다. GKE API는 개인 Google 토큰의 기존 권한을 적용한다.

**제약:** 이메일 허용 목록과 신뢰 프록시를 명시하고 비밀값을 코드·로그에 기록하지 않는다. 실제 클라우드 조회·자격 증명 발급·Secret 생성·배포·Git 게시에는 별도 구체적 승인이 필요하다.

1. Helm 렌더와 인증 경계 회귀 테스트를 먼저 작성한다.
2. 별도 차트와 이미지 고정, 운영 절차 및 ADR을 작성한다.
3. 테스트와 인벤토리를 검증하고 기존 AWS 경로 회귀를 확인한다.
4. 실제 OAuth 동의, ALB 경로, 원래 토큰 만료 후 갱신 검증을 포함하는 배포안을 준비한다.

완료 기준: 비인가 접근·헤더 위조·허용 목록 우회가 차단되고 기존 경로가 보존된다. 실제 Google 로그인과 만료 후 갱신은 승인된 배포 및 사용자 브라우저 검증 전까지 미완료로 둔다.
